# Política de privacidad

Última actualización: 31 de octubre de 2026.

OpenCommerceIndex es un directorio abierto de tiendas publicado como archivos estáticos y una skill de instrucciones para asistentes de IA. No tenemos servidores propios, bases de datos, cuentas de usuario ni herramientas de analítica.

## El sitio web

Este sitio se sirve desde GitHub Pages. No usa cookies, no incluye analítica ni rastreadores de terceros y no tiene formularios propios. GitHub puede registrar datos técnicos de las visitas (como la dirección IP) según su propia [política de privacidad](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). Los enlaces a tiendas llevan a sitios de terceros con sus propias políticas.

## El plugin y la skill para asistentes

El plugin son instrucciones. No ejecuta código, no envía nada al proyecto y no guarda estado. Cuando pedís un producto, tu asistente usa sus propias herramientas de navegación para leer los archivos públicos del directorio y las páginas públicas de las tiendas listadas, dentro de lo que cada tienda permite en su `robots.txt`. Esas solicitudes las hace tu asistente bajo la política de su proveedor; nosotros no las vemos. Las tiendas ven esas visitas como cualquier otra.

No recogemos datos personales, historial de compras ni conversaciones. No hay cuentas, pagos ni publicidad.

## Formularios y contribuciones en GitHub

Las altas, correcciones y reclamos de tiendas se hacen con formularios públicos de GitHub Issues. Todo lo que se escribe allí es público y queda sujeto a la [política de privacidad de GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). Pedimos no incluir datos privados; si alguien los publica por error, los retiramos a pedido y nunca los copiamos a las fichas.

## Datos sobre tiendas

Las fichas describen comercios, no personas: nombre comercial, sitio web, qué venden, dónde entregan y cómo buscar en su sitio. No publicamos datos de contacto personales, clientes, precios ni catálogos. Cualquier tienda puede pedir corrección o baja con los [formularios del índice](https://github.com/ignaciolarranaga/open-commerce-index/issues/new/choose).
