# Cursor

:::status
:::

Cursor (2.5 o posterior) instala plugins desde marketplaces en GitHub.

:::steps
1. Agregá el marketplace desde la línea de comandos: `cursor-agent plugin marketplace add https://github.com/ignaciolarranaga/open-commerce-plugin`
2. Ejecutá `cursor-agent`, escribí `/plugin`, abrí la pestaña **Marketplace** y elegí **open-commerce**.
3. Iniciá una sesión nueva y pedí tu producto.
:::

Cursor no tiene todavía un comando de instalación no interactivo; la instalación se hace desde el panel.
