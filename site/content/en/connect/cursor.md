# Cursor

:::status
:::

Cursor (2.5 or later) installs plugins from marketplaces on GitHub.

:::steps
1. Add the marketplace from the command line: `cursor-agent plugin marketplace add https://github.com/ignaciolarranaga/open-commerce-plugin`
2. Run `cursor-agent`, type `/plugin`, open the **Marketplace** tab and pick **open-commerce**.
3. Start a new session and ask for your product.
:::

Cursor has no non-interactive install command yet; installation happens from the panel.
