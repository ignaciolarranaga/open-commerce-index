# ChatGPT

:::status
:::

OpenAI allows publishing skills-only plugins, with no server, after a review. Our package is prepared for that path, but **it has not been submitted or approved yet**. Until then there is no install button.

In the meantime, if you use ChatGPT with browsing, you can paste the skill content published in the [plugin repository](https://github.com/ignaciolarranaga/open-commerce-plugin/blob/main/plugins/open-commerce/skills/shop/SKILL.md) into the conversation and ask for your product. That is a manual test, not a supported integration.

We will update this page when the status changes. You can follow it in the [compatibility matrix](https://github.com/ignaciolarranaga/open-commerce-plugin/blob/main/docs/compatibility.md).
