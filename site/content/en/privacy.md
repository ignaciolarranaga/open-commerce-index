# Privacy policy

Last updated: 31 October 2026.

OpenCommerceIndex is an open directory of stores published as static files, plus an instruction skill for AI assistants. We run no servers, databases, user accounts or analytics tools.

## The website

This site is served from GitHub Pages. It uses no cookies, includes no analytics or third-party trackers and has no forms of its own. GitHub may log technical data about visits (such as IP addresses) under its own [privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). Links to stores lead to third-party sites with their own policies.

## The plugin and the assistant skill

The plugin is instructions. It runs no code, sends nothing to the project and keeps no state. When you ask for a product, your assistant uses its own browsing tools to read the directory's public files and the public pages of the listed stores, within what each store allows in its `robots.txt`. Those requests are made by your assistant under its provider's policy; we never see them. Stores see those visits like any other.

We collect no personal data, purchase history or conversations. There are no accounts, payments or advertising.

## Forms and contributions on GitHub

Store listings, corrections and claims use public GitHub Issue forms. Everything written there is public and subject to [GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). We ask contributors not to include private data; if someone posts it by mistake, we remove it on request and never copy it into profiles.

## Data about stores

Profiles describe businesses, not people: trade name, website, what they sell, where they deliver and how to search their site. We publish no personal contact details, customer data, prices or catalogs. Any store can request a correction or removal through the [index forms](https://github.com/ignaciolarranaga/open-commerce-index/issues/new/choose).
