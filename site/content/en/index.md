# Find where to buy by asking your assistant

OpenCommerceIndex is an open directory of online stores. Your assistant (ChatGPT, Claude or others) reads it to learn which stores exist, what they sell, where they deliver and how to search each one. Then it checks each store live and shows you the options.

:::example
**You:** "I want a Philips LatteGo 5500 coffee machine in Montevideo. Where can I get one?"

**Your assistant:** Reads the directory, picks the appliance stores that deliver in Uruguay, searches the model in each and answers with the exact product name, the model code, the price as shown by the store, availability, the link and the time it checked. If a store could not be reached, it says so instead of guessing.
:::

## How it works

1. The directory lives on GitHub and is published as static files. Anyone can read it, copy it and propose changes.
2. You install a plugin or a skill in your assistant. They are instructions, not a service: no servers of ours sit in between.
3. When you ask for a product, the assistant picks the relevant stores from the directory and checks their sites with its own browsing tools.
4. Prices and stock always come from the store at the time of the query. We neither store nor publish them.

## What to expect

- Options from real stores, with the exact model when the store states it, the price in the currency the store shows, and the link to buy.
- Honesty about what could not be seen: a blocked or offline store is reported as such, never as "does not sell this product".
- Coverage that grows with the community. We start with stores in Uruguay and add countries as verified stores arrive.

## What it is not

Not a price comparison site with stored prices, not a marketplace, not a commercial recommendation. Each profile says how to find information on a store, not whether you should buy there. Purchases always happen on the store's own site.
